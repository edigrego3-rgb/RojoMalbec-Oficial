# Rojo Malbec - Blend Builder 🌶️

App móvil PWA para que los clientes de Rojo Malbec puedan explorar ingredientes y solicitar blends personalizados.

## 🚀 Demo

Visita: [blend.rojomalbec.com.ar](https://tu-usuario.github.io/blend-builder)

## ✨ Características

- 📱 Instalable como app móvil (PWA)
- 🔍 Explorador de 60+ ingredientes
- 🏷️ Filtros por perfil aromático
- 🧪 Armá tu blend personalizado
- 📲 Envío de pedido por WhatsApp

## 📦 Tecnologías

- HTML5 / CSS3 / JavaScript (Vanilla)
- PWA con Service Worker
- Diseño Mobile-First

## 🛠️ Instalación Local

```bash
# Clonar repositorio
git clone https://github.com/tu-usuario/blend-builder.git

# Abrir en navegador
# Simplemente abre index.html en tu navegador
```

## ⚙️ Configuración

Edita `app.js` y cambia el número de WhatsApp:

```javascript
const WHATSAPP_NUMBER = '5493511234567'; // Tu número
```

## 🌐 Deploy en GitHub Pages

1. Crear repositorio en GitHub
2. Subir archivos
3. Settings → Pages → Source: main branch
4. Tu app estará en: `https://tu-usuario.github.io/blend-builder`
